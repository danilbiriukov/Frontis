# Покрытие и итоги тестов

Frontis передаёт готовый LCOV официальному плагину Code PushUp 0.126.4. Сначала он ищет `coverage/lcov.info`, затем `lcov.info` в корне проекта. В `report.json` сохраняются аудиты измеренных строк, ветвей и функций. В `result.json` для покрытия строк указаны нижний порог, цель и разрывы до них в процентных пунктах. `reportDate` берётся из времени изменения файла LCOV.

Если готового LCOV нет, Frontis запускает `testCommand` в корне проекта. Команда должна записать LCOV по одному из поддерживаемых путей и может записать итоги Jest или Vitest в `.frontis/test-results.json`. Покрытие принимается после успешного завершения команды и только из файла, который появился или обновился во время прогона. Для итогов тестов в этом режиме тоже нужен новый или обновлённый JSON.

Если команда упала, подтверждённые падения и пропуски из нового JSON сохраняются. Покрытие получает причину пропуска. Frontis запоминает состояние оставшихся файлов LCOV в `.frontis/coverage-command.json` и пропускает эти версии файлов при следующих запусках. После успешного прогона или внешнего обновления файла пригодное покрытие снова участвует в оценке.

При готовом LCOV команда не запускается. Если проект заранее записал `.frontis/test-results.json`, Frontis читает его отдельно. Покрытие и итоги тестов находятся в двух проверках показателя `coverage`. Обе используют тайм-аут из `modules.coverage.timeoutMs` и отключаются через `modules.coverage.enabled`.

Примеры команд для записи JSON приведены в [форматах Jest и Vitest](test-results.md). Форматы флагов подтверждены документацией инструментов. [Jest](https://jestjs.io/docs/cli#--outputfilefilename) · [Vitest](https://vitest.dev/guide/reporters#json-reporter)
