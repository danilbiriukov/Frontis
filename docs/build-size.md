# Размер сборки

`createBuildSizeCollector({ buildDir, maxMb })` считает размер существующей папки сборки и ничего не собирает. `buildDir` — абсолютный путь из разрешённой конфигурации, `maxMb` — `thresholds.buildSize.maxMb`.

Учитываются все обычные файлы во вложенных папках. Символические ссылки не учитываются. В `data` есть путь папки от корня проекта, `totalBytes`, число файлов `files` и пять крупнейших файлов `largest` с путями от корня проекта. Файлы одного размера упорядочены по пути.

Порог переводится в байты так же, как в `core/rules.ts`: `maxBytes = floor(maxMb × 1 048 576)`. Размер, равный порогу, в пределах нормы. `exceeded` равен `true` только при `totalBytes > maxBytes`, и тогда есть находка `build-size-exceeded` уровня `error`.

| `status` | `code` | Когда |
| --- | --- | --- |
| `ok` | | В папке есть хотя бы один файл |
| `no-data` | `no-build-dir` | Папки нет или по пути лежит файл |
| `no-data` | `build-dir-unreadable` | Нет доступа к папке или её содержимому |
| `no-data` | `empty-build-dir` | Папка пуста |
