# Конфигурация движка

Frontis читает `frontis.config` и готовит настройки Code PushUp в памяти. Корнем проекта служит каталог конфига или заданный `projectDir`. Явные относительные пути, включая `buildDir` и `outFile`, считаются от каталога конфига.

По умолчанию сборка лежит в `dist` от корня проекта, а HTML-отчёт в `.frontis/report.html`. Укажите `buildDir`, если сборка находится в другой папке, например `apps/client/dist`. Остальные артефакты запуска хранятся в `.frontis/` от корня проекта. Параметр `open: true` включает открытие HTML после записи отчёта.

Менеджер пакетов берётся из метаданных проекта. Приоритет у поля `packageManager` в `package.json`, далее используются lock-файлы.

В корне проекта Frontis сначала ищет `eslint.config` с расширениями `.js`, `.mjs`, `.cjs`, `.ts`, `.mts` и `.cts`. Затем проверяет `.eslintrc` с расширениями `.js`, `.cjs`, `.yaml`, `.yml`, `.json` и без расширения. Модули `lint` и `prettier` включаются отдельно.

Для покрытия используется `coverage/lcov.info`, а при его отсутствии `lcov.info` в корне. Если готового отчёта нет и задана `testCommand`, адаптер получает команду и ожидаемый путь `coverage/lcov.info`.

## Подключение запуска

`loadEngineConfig(cwd, adapters)` загружает конфиг и готовит список `plugins` для `runGuardedPlugins(config.projectDir, plugins)`. Таблица `adapters` связывает имена модулей Frontis с именами пакетов или абсолютными `file:` URL их обёрток. Изолированный процесс вызывает `prepare` обёртки, получает `PluginConfig` и передаёт его Code PushUp. Файл `code-pushup.config` для этого не нужен. [Контракт изолированного запуска](plugin-guard.md)

В `noData` возвращаются причины пропусков, определённые до запуска. Для отключённого модуля используется `disabled`, для отсутствующей обёртки `adapter-unavailable`. Файлы конфигурации и покрытия на этом этапе проверяются по пути. Их содержимое проверяют соответствующие адаптеры.

`frontis run` уже выполняет план для [плагинов Frontis](frontis-plugins.md) и сохраняет их причины пропуска. Запуск остальных модулей и запись отчётов относятся к [#10](https://github.com/danilbiriukov/Frontis/issues/10). Запуск тестов для получения покрытия относится к [#26](https://github.com/danilbiriukov/Frontis/issues/26).
