# Места использования отстающих пакетов

`frontis run` добавляет карту в HTML и в опциональное поле `importMap` файла `result.json` версии 1. Карта показывает, где используются наиболее отстающие зависимости, и не влияет на балл, рекомендации или код выхода. HTML показывает до 10 мест на пакет, полный список хранится в JSON.

Для карты CLI использует проверенные версии из подтверждённых групп `npm outdated`. Если реестр ответил только для одной группы, карта может показать пакеты этой группы. Пустая карта означает, что в подтверждённых данных обеих групп отстающих пакетов нет. При отключённом `outdated` карта показывает «Нет данных». Для сбора карты действует лимит времени модуля `outdated`. [Задача #22](https://github.com/danilbiriukov/Frontis/issues/22)

`createImportMapCollector({ packages, limit })` принимает список `{ name, current, latest }`. Значение `undefined` означает, что сведений нет. По умолчанию сборщик выбирает до пяти пакетов с наибольшим отставанием. Сначала он сравнивает разницу major, при равном major разницу minor, затем patch. Пакеты с одинаковым отставанием упорядочены по имени.

В Git список файлов учитывает `.gitignore` для неотслеживаемых файлов. Вне Git сборщик обходит каталоги проекта. В обоих случаях он пропускает `node_modules`, `dist`, `build`, `coverage`, скрытые каталоги и символические ссылки. Просматриваются файлы `.js`, `.jsx`, `.ts`, `.tsx`, `.mjs`, `.cjs`, `.mts`, `.cts`, `.vue`, `.svelte` и `.astro`.

Учитываются `import … from`, `export … from`, `import '…'`, `import('…')` и `require('…')`. Импорт засчитывается пакету, если спецификатор равен имени или начинается с `имя/`. Поэтому `lodash/fp` относится к `lodash`, а `lodash-es` нет. Импорты внутри комментариев и строк не отличаются от настоящих. Импорты в каждом файле сохраняются с номером строки и полным спецификатором, порядок стабилен.

| `status` | `code` | Когда |
| --- | --- | --- |
| `ok` | | В JSON есть `packages` с версиями и импортами и `scannedFiles` с числом прочитанных файлов. При пустом списке файловый обход пропускается |
| `no-data` | `no-outdated-data` | Сведений об отставании нет |
| `no-data` | `no-sources` | Не удалось прочитать ни одного исходного файла |
| `no-data` | `import-map-timeout` | Истёк лимит времени поиска |
| `no-data` | `import-map-failed` | Поиск завершился ошибкой |
