# Проверки качества кода

`frontis run` запускает ESLint и Prettier отдельно. Их можно отключать независимо через `modules.lint.enabled` и `modules.prettier.enabled`. В `result.json` результаты обеих проверок входят в показатель `codeQuality`. Если одна проверка пропущена, показатель помечается как неполный, а находки второй проверки остаются в оценке и рекомендациях.

## ESLint

Frontis ищет файл настроек ESLint в корне проекта и использует ESLint из зависимостей проекта. Для ESLint 10 нужен `eslint.config.*`. При проверке ESLint 10 ищет настройки от каждого файла и учитывает вложенные конфигурации. Для ESLint 9 доступны плоская конфигурация и `.eslintrc`. Адаптер также принимает ESLint 8 начиная с 8.46 для `.eslintrc`, а плоская конфигурация требует API `loadESLint`. Список имён файлов описан в [настройках движка](engine-config.md).

С ESLint 10 Frontis работает на Node.js 22.13.0 и новее в ветке 22.x, а также на Node.js 24 и новее. Frontis проверяет требования из установленного пакета ESLint. [Миграция на ESLint 10](https://eslint.org/docs/latest/use/migrate-to-10.0.0)

ESLint проверяет каталог проекта с учётом исключений из конфигурации. Из одного вызова `lintFiles` Frontis получает список файлов, сообщения и ошибки разбора. Для ESLint 8 и 9 метаданные правил формирует фабрика Code PushUp 0.126.4. Для ESLint 10 метаданные сработавших правил берутся из API установленного ESLint. Во всех версиях преобразователь Code PushUp формирует стабильные идентификаторы аудитов с учётом параметров правила. [Node.js API ESLint](https://eslint.org/docs/latest/integrate/nodejs-api)

В `report.json` рядом с аудитами правил записываются `eslint/frontis-checked-files` и `eslint/frontis-parse-errors`. В первом хранится число файлов и таблица из десяти наиболее частых правил. Нарушения вариантов одного правила суммируются. Во втором хранятся ошибки разбора с путём и строкой, если ESLint её сообщил. Прочие сообщения без идентификатора правила при наличии попадают в `eslint/frontis-eslint-messages`.

| Код | Причина |
| --- | --- |
| `no-eslint-config` | В корне проекта нет файла настроек |
| `eslint-not-installed` | ESLint не найден из каталога проекта |
| `eslint-unsupported` | Версия ESLint не поддерживает выбранный формат |
| `eslint-legacy-config-unsupported` | Для ESLint 10 требуется перенести `.eslintrc` в `eslint.config.*` |
| `eslint-node-unsupported` | Текущий Node.js не соответствует требованиям установленного ESLint 10 |
| `no-files` | ESLint не проверил ни одного файла |
| `eslint-coverage-unconfirmed` | По данным запуска нельзя подтвердить проверку файлов |
| `eslint-failed` | Проверка прервалась из-за ошибки инструмента или настроек |

При успешной проверке хотя бы одного файла в `checks[].facts` доступны `checkedFiles`, `errors`, `warnings` и `parseErrors`. Ошибки разбора входят в общий счётчик ошибок. Топ правил хранится в `checks[].details.rules`.
