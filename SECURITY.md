# Как сообщить об уязвимости

Откройте вкладку [Security → Advisories](https://github.com/danilbiriukov/Frontis/security/advisories) и нажмите **Report a vulnerability**. Используйте приватную форму GitHub, чтобы детали уязвимости оставались доступны только участникам обсуждения.

Укажите версии Frontis и Node.js, шаги воспроизведения и возможные последствия. Перед отправкой удалите из примеров и журналов токены, пароли и данные пользователей.
